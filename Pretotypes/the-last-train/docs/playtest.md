# 线下实验指南（待执行）

## 要验证什么

私人信息和可追踪后果，是否让朋友主动交流、协商承诺，并在结尾记得具体选择。程序跑通只证明实现可用，不证明假设成立。

## 准备

招募两组各 4 人朋友，每组完整玩一局，预留约 25 分钟与 5 分钟访谈。电脑运行服务器，所有手机连接同一 Wi-Fi；使用真人房间，不使用 bot。告知参与者可以转述或展示秘密，无需演戏或假嗓音，愿望没有排名。

用观察编号 P1–P4 记人，不记录姓名。房主在结尾可下载匿名事件日志对照资源变化；游戏不录音、不分析真实对话。

## 结束后逐人询问

1. 你哪次真的需要朋友的信息？
2. 哪次选择让你觉得结果不同？能说出选择和后果吗？
3. 你更关心共同结局还是个人愿望？
4. 手机让你更投入，还是打断聊天？
5. 你愿意换一个角色再玩吗？为什么？

## 预设继续探索信号

每章至少 3/4 玩家参与讨论；至少两章出现基于不同信息的协商；至少 3/4 玩家能回忆一项自己的选择与对应后果；至少 3/4 愿意换角色再玩。这些是项目自己的探索阈值，不是行业标准。

若只出现各自读卡、各自点按钮，优先调整信息互补、讨论提示和后果可见性；不要直接增加剧情长度。若私人愿望导致无趣决定，降低其权重或调整为回顾标签，不增加惩罚。
